Код

Задача. Этот код не выполняется должным образом. Попробуйте выяснить причину. 

function multiply(a, b) {
	  a * b
	}

Решение: Функция не возвращает значение. Добавим оператор return. 

function multiply(a, b) {
	  return a * b;
	}
